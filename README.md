# Ecosystem-Sim: Data Pipeline Engineering Exercise
I'm using a simple ecosystem simulation to create a data pipeline for ETL & analysis. The objective is to track the simulator's events and extract insightful data for analysis & visualization. 

## LATEST UPDATES

## (20/8/2025) Sprint 1: The Data Pipeline

Our primary goal for this first phase was to establish a live, event-driven data pipeline. We've successfully built the foundational infrastructure for that.


### The Data Producer (React Front End):

We have a fully functional, interactive React application running on your local machine.

We've successfully modified it to identify a key business event (CREATURE_BIRTH).


### The Data Collector (Python Backend):

We've built a lightweight but functional API endpoint using Flask.

This server is capable of receiving and processing incoming data from a web application.

### The Connection (The Pipeline Itself):

We've successfully configured the React app to send POST requests to the Flask API.

We've confirmed that data is flowing from the front end to the back end in real-time.

### Environment & Troubleshooting:

We worked through significant real-world deployment and environment challenges, including WSL networking, Windows Firewall configuration, and local dependency management. This is a critical part of any data engineering project.

In short, we've successfully built and debugged a proof-of-concept for an event-driven data collection system.

## What We Have Left to Do (The Backlog)
